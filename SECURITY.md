# Security Policy

## Supported release

Tokyo Nights Racing v0.1.0 is the supported portfolio release.

## Reporting a security or privacy issue

Do not post credentials, private file paths, local machine details, restricted
third-party assets, or unpublished build material in a public issue.

Report sensitive findings privately to:

`codie.shannon.work@outlook.com`

## Project boundary

Tokyo Nights Racing is a historical Unity/C# systems portfolio prototype. It
is not a live service, commercial game, or security-critical production
system.

The public repository preserves authored source, project settings,
documentation, and approved evidence. Third-party assets remain governed by
their own licences and are not relicensed by the repository MIT licence.
