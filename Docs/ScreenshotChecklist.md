# Screenshot Checklist

Use these screenshots for the Tokyo Nights Racing GitHub README and portfolio presentation.

Create this folder in the repo:

```text
Screenshots/
```

## Required Screenshots

### 01-main-menu.png

Main menu carousel with title card visible.

Shows:

- Main menu polish
- Carousel UI
- Project identity

### 02-settings-menu.png

Settings menu with audio, quality, fullscreen, and traffic density visible.

Shows:

- Settings system
- Persistent options
- Traffic density setting

### 03-garage-vehicle-selection.png

Garage vehicle preview with UI visible.

Shows:

- Garage system
- Vehicle selection
- Vehicle database presentation

### 04-vehicle-roster.png

A view/collage showing multiple vehicle classes if possible.

Shows:

- Road
- OffRoad
- AllTerrain
- MonsterTruck

This is optional if it takes too long, but useful for the README.

### 05-race-modes-selected.png

Main menu with Race Modes selected.

Shows:

- Race Modes menu flow
- Main menu integration

### 06-race-grid-start.png

Race grid or countdown at the start of a race.

Shows:

- Grid start system
- Player and AI racers
- RaceScene setup

### 07-ai-racing-road.png

Player racing against AI on a curved road track.

Shows:

- AI racing
- Race HUD
- Curved-track behavior
- Checkpoint race flow

This is one of the most important screenshots.

### 08-ai-racing-monster-truck.png

Monster truck or alternate vehicle class racing against AI.

Shows:

- Vehicle class support
- Correct vehicle/track matching
- AI class filtering

### 09-freeroam-city-traffic.png

Freeroam city scene with player car and traffic cars visible.

Shows:

- Freeroam gameplay
- Traffic spawner
- Traffic density/world feel

### 10-mission-marker-race-start.png

Player near a mission marker with interaction prompt visible.

Shows:

- Freeroam mission marker system
- Race launching outside main menu

### 11-race-results-screen.png

Results screen after finishing a race.

Shows:

- Completed race loop
- Results UI
- Return/retry flow

## Optional Screenshot

### 12-return-to-main-menu.png

Main menu after returning from Race Modes with Race Modes selected.

Shows:

- Return-state handling
- Scene flow polish
